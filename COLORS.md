# Answer Card Color Guide

Standard colors for multiple-choice slides and student voting cards (2–4 options).

## Palette

| Choice | Color | Hex | Letter/text color |
|---|---|---|---|
| A | Blue | `#0072B2` | White |
| B | Orange | `#E69F00` | Black |
| C | Teal-green | `#009E73` | Black |
| D | Pink-purple | `#CC79A7` | Black |

Based on the Okabe-Ito colorblind-safe palette.

## Rules

1. **Fixed mapping.** A is always blue, B always orange, C always teal-green, D always pink-purple. Never reshuffle between questions.
2. **Use options in order.** 2 choices = A + B. 3 choices = A + B + C. Never skip a color (don't use A + C).
3. **Never color alone.** Every card and every slide option shows a large letter. Optional shapes: A = circle, B = square, C = triangle, D = star.
4. **No right/wrong colors.** Don't use red or green as a pair, and don't use color to signal correctness. Reveal the answer separately (e.g., a checkmark or highlight after voting).
5. **Match slide to card.** Each option on the slide sits in a block of its card's color, with the same letter.

## Slide layout

- One colored block per option, with the letter on the left and the answer text beside it.
- Answer text in dark gray/black on a white or light background; only the letter block carries the color fill.
- Keep letters at least 40 pt on slides.

## Card printing

- Matte cardstock (glossy causes glare under classroom lights).
- Solid color fill, with the letter at least 2 inches tall.
- Check legibility from the back of the room and in a grayscale printout.
