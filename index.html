Using the slides

Each deck is a single web page that runs in any browser, including on a phone. Usually you'll get a direct link in class; every deck lives at slides.manzano.dev/<course>/<deck>.html.

How it's made

Every deck is written in plain Markdown and turned into HTML with Marp, using a small custom theme. Short questions like “two truths and a lie” show up as colored boxes, and the colors are chosen so none of them hints at the right answer.
